Memory Under Pressure: How Fixed-Size State Remembers, Updates, Interferes & Forgets

Artifact: memory-under-pressure-flax.vercel.app • Repo: github.com/IshantTripathi/memory-under-pressure • Author: Ishant Tripathi • Target: ML/AI Engineers
1. The Central Falsifiable Claim Core Thesis
“A fixed-size evolving state can process sequences whose duration grows without allocating a new memory slot for every token, but limited state capacity can cause interference and forgetting.”

A fixed-size state representation remains fixed with respect to sequence length T for a fixed model configuration (O(d²) matrix parameters), avoiding linear growth in cached-token memory (O(T · d) in Transformer KV caches). However, fixed representation size does not imply unlimited capacity or zero information loss: past facts are superposed, creating cross-talk noise and selective forgetting under sequence pressure.

2. Recurrent Mechanism & Retrieval Decomposition Math Substrate

The educational substrate models an explicit 2D matrix state St ∈ ℝd × d. Given normalized key-value pairs (kt, vt), the state updates incrementally via:

St = λ St-1 + η (vt ⊗ ktT) = ∑τ=1t λt-τ η (vτ kτT)

Probing with query vector q retrieves v̂ = St q, which decomposes analytically into signal plus cross-talk noise:

v̂ = λt-ttarget η (ktargetT q) vtarget + ∑τ≠target λt-τ η (kτT q) vτ

Signal-to-Noise Ratio: SNRdB = 10 log10(||s||² / (||n||² + ε)). When T ≤ d and keys form an orthonormal set (kτT q = 0 for τ ≠ target), noise is zero. But because ℝd supports at most d mutually orthogonal directions, storing T > d associations forces non-orthogonal superpositions that accumulate cross-talk noise.

3. Why It Matters: KV-Cache Pressure Engineering Context

In standard Transformers, caching past token representations induces linear growth in cached-token memory (O(T · d · L)), leading to GPU VRAM exhaustion, severe memory-bandwidth bottlenecks during autoregressive decoding, and high serving costs on long-horizon reasoning tasks.

5. What the Learner Can Test (Interactive Simulator) 6 Presets

The interactive artifact provides an intentionally small educational associative-memory model inspired by recurrent state architectures, demonstrating 6 deterministic test regimes (Mulberry32 PRNG):

Clean Baseline (T=5, d=16) Orthonormal keys; noise = 0.000; SNR = +90 dB; 100% exact retrieval.
Capacity Bound (T=16, d=16) State approaches full rank; mild cross-talk begins (SNR = +6.9 dB).
Severe Overload (T=60, d=8) T >> d; cross-talk exceeds signal (SNR = -8.5 dB); interference failure.
Selective Decay (T=35, d=16, λ=0.92) Norm bounded; early fact decays by 94.1% (λ34); recency amnesia.
Key Collision (T=20, d=16, ρ=0.70) Correlated keys cause leakage even with relatively large state size.
Break-It Stress (T=250, d=8) Empirical phase-transition curve mapping accuracy vs T/d ratio.
6. Pathway Frontier Connection: BDH & BDH-CQ Frontier Role

Pathway researchers resolved recurrent representational bottlenecks in Dragon Hatchling (BDH, arXiv:2509.26507) by reformulating attention as dynamic synaptic plasticity over sparse particle graphs with Q=K Hebbian self-affinity and non-negative activations. BDH-CQ (arXiv:2608.09888) extends this to in-context learning: demonstrations update recurrent memory at inference time, and queries are solved iteratively in high-dimensional latent space without verbalizing text tokens.

Published Result: On public ARC-AGI-1 evaluation, a 150M BDH-CQ model achieved 29.5% pass@2 at $0.0007 per task (under 1/10th cent), establishing a reported cost-efficiency Pareto point.

7. Scientific Boundaries & Limitations Rigor

1. Finite Rank: A matrix S ∈ ℝd × d has rank ≤ d; it cannot store arbitrarily many independent associations without interference as T grows relative to d.
2. Decay Dilemma: In this recurrence, λ < 1 prevents unbounded norm growth but creates an exponential forgetting horizon (λt).
3. Quasi-Orthogonality: Clustered semantic embeddings cause cross-talk earlier than orthogonal codebooks.
4. Toy Demarcation: The simulator is an educational toy model, not production BDH.
